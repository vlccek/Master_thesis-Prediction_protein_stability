# Classification Dataset Preparation

Tools for building and splitting datasets for protein stability classification tasks, designed for parallel processing on HPC clusters.

## Contents
- **`input_chunks/`**: Data split into chunks for parallel processing (generated from input datasets).
- **`splitdataset_for_metacetnrum_arrayjobs.py`**: Script to prepare array job inputs.
- **`array_job.sh`**: Submission script for PBS/Metacentrum.
