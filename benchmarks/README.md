# Benchmarks

Scripts and datasets for evaluating model performance against standard protein stability benchmarks.

## Contents
- **`datasets/`**: Prepared (normalized) benchmark data (S350, BenchStab, PonSol) (Citation are at the main text `thesis_text/`).
- **`run_all_benchmarks.sh`**: Main execution script for running all benchmarks.
- **`run_inference.py`**: Generic inference script for model evaluation.
